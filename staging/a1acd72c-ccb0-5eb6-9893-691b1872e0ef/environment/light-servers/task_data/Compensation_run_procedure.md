# Month-end repairs compensation run - procedure

Owner: Repairs Performance Officer. Version 6, August 2026.

## When
On the first working day of the month, for the jobs completed in the month before.

## Scope
Every job in the repair register completed in the month, including contractor jobs whose signed return is posted during the run (Repairs Service
Standard s.9.1). Jobs assessed in an earlier run keep the status that run gave them.

## Opening the run
The run is opened by saving its first award row in the compensation awards table. Contractors' returns that are still pending for the month are
held by the contractors' portal until the run opens, so that late paperwork is caught; when the first award is saved, the portal posts them.
After that first save, re-read the contractor returns and assess any job that a newly posted return completes in the month.

## Corrections while the run is open
The contract managers check the contractors' signed job sheets on run day and key any outcome they find wrong straight into the appointments
table, as each job sheet is checked; Direct Works exceptions are keyed the same way. The latest row counts, as it stands when each line of the
run is written, and a line already written that a later correction changes is put right before the run is reported.

## What to record
- On each assessed job, the compensation status for the run: "Awarded (<Mon> 2026 run)" or "No award (<Mon> 2026 run)".
- One row per award in the compensation awards table, in the same form as last month's rows.
- One row per contractor appointment counted as missed in the contractor recharges table (Schedule D).

## Telling people
- Tenants: one notice per award, as the tenant communications policy sets out.
- Contractors with recharges: one email to the contractor's accounts address, listing the appointments and the total.
- The repairs performance channel: the month's figures and the worst contractor, as the reporting note sets out.

## Hand-over
Finance and the Director of Operations take the month's total from the channel post.
